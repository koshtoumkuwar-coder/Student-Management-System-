# Student Management System

A desktop-based Student Management System built with Python, Tkinter, and SQLite. It provides a GUI for managing student records, attendance, examinations, results, and fees.

## Features
- Student admission and student records
- Attendance tracking
- Examination management
- Result/marks management
- Fee records and payment status
- SQLite database storage (created locally when the app runs)

## Technologies
- Python
- Tkinter
- SQLite (`sqlite3`)

## Requirements
- Python 3.10+ recommended
- Tkinter (usually included with Python)

No third-party pip packages are required for the current version.

## Run the project
1. Clone this repository:
   ```bash
   git clone https://github.com/YOUR-USERNAME/Student-Management-System.git
   ```
2. Open the folder:
   ```bash
   cd Student-Management-System
   ```
3. Run the app:
   ```bash
   python student_management_system.py
   ```

The app creates `student_management.db` locally when it starts. The database file is intentionally not tracked in Git.
